# Glowtide player page

The page [Glowtide](https://github.com/cynicalk/glowtide)'s YouTube player runs in: YouTube's
official IFrame player, driven by the Glowtide window that frames it. Published with GitHub
Pages at https://cynicalk.github.io/glowtide-player/.

It's a copy of `player-page/` in the Glowtide repository: change it there.
